# Task 02 — Missing Command

## 1. 为什么 ./tools/recruit-info 可以运行，而直接输入 recruit-info 找不到它？

`./tools/recruit-info` 使用的是相对路径，明确告诉 Shell 要执行的文件位于当前目录的 tools 子目录下，因此 Shell 可以直接找到并执行它。

而直接输入 `recruit-info` 时，Shell 会去 PATH 环境变量中列出的所有目录里依次查找名为 recruit-info 的可执行文件。因为 tools/ 目录不在 PATH 中，Shell 找不到该文件，所以报错 command not found。

## 2. 输入 ls 时，Shell 是如何找到对应程序的？

当我们在 Shell 中输入 ls 时，Shell 会按照以下步骤查找：

1. Shell 读取 PATH 环境变量，它包含了多个目录路径，例如 /usr/local/bin、/usr/bin、/bin 等。
2. Shell 按顺序在这些目录中查找名为 ls 的可执行文件。
3. 通常在 /usr/bin/ls 或 /bin/ls 中找到。
4. 找到后，Shell 执行该程序并显示结果。

可以使用 which ls 或 command -v ls 命令查看 ls 的具体路径。
